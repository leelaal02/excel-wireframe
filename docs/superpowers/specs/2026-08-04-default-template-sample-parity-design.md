# 기본 템플릿 샘플 동형화 + 표지 메타 반영 — 설계

작성일: 2026-08-04

## 1. 목표

두 가지를 한다.

1. **기본 템플릿을 실제 화면설계서와 같은 모양으로 만든다.** 지금은 16:9(13.33 × 7.50 in)에
   임의 배치이고, 실제 샘플(`화면설계서_저작권_발행기관.정산처_발행기관관리_v1.0_20260427.pptx`)의
   화면 페이지는 10.83 × 7.50 in다. 샘플 2페이지(index 1, `test_sample_e2e.py`가
   `source_slide: 1`로 쓰는 그 페이지)의 좌표·크기·글꼴을 실측값 그대로 승계한다.
2. **머리글·꼬리말 글자를 Excel 표지에서 가져온다.** 현재 파이프라인에는 문서 단위 텍스트가
   존재하지 않는다. 표지 시트의 라벨-값 쌍을 읽어 `screens.json`의 `meta`에 담고,
   `build.py`가 같은 이름의 도형에 채운다.

## 2. 비목표

- 샘플 pptx를 스킬에 번들하지 않는다. 코드로 생성한다(기존 원칙 유지).
- 샘플의 저작권 문구·회사 브랜딩을 복제하지 않는다. 기본 템플릿은 전역 설치되어
  제3자 산출물에도 그대로 들어가므로, 남의 저작권 표기가 박히면 안 된다.
- 사용자가 `--template`을 주면 이 설계는 관여하지 않는다. 템플릿이 언제나 우선한다.
- 표지 슬라이드를 만들지 않는다. 표지 시트는 **값의 출처**일 뿐 페이지가 되지 않는다.

## 3. 배경 — 샘플 2페이지의 방식과 그 한계

샘플 2페이지는 도형이 여덟 개뿐이고, 문서 껍데기를 레이아웃에 위임한다.

| 요소 | 형태 | 슬라이드에서 편집 |
|---|---|---|
| 제목 | placeholder (TITLE, idx=0), 비어 있음 | 가능 |
| 화면ID | placeholder (BODY, idx=2), 비어 있음 | 가능 |
| 화면 이미지 | PICTURE 1개 | 가능 |
| 상세 | 4행 2열 표 5개 | 가능 |
| 상단 띠 / 구분선 / 하단 바 / 쪽번호 / 날짜 | 레이아웃 `내용설명연결`이 그림 | **불가** |

요구는 "모든 글자를 수정할 수 있는 형태"이므로 이 방식을 그대로 쓸 수 없다. 레이아웃에
갇힌 요소는 슬라이드에서 클릭되지 않고, 화면마다 값을 달리할 수도 없다.

**결정: 기하와 서식은 2페이지를 그대로 따르되, 레이아웃에 있던 껍데기 요소를 슬라이드 위
도형으로 끌어올린다.** 눈으로는 2페이지와 구분되지 않으면서 모든 글자가 편집 가능해진다.

## 5. 표지 메타 추출

### 대상 데이터

두 샘플 Excel(`짧은 버전.xlsx`, `긴 버전.xlsx`)의 표지 시트는 구조가 동일하다.

```
B3  화면설계서 & 단위테스트 케이스 리스트     ← 단독 셀
B4  멀티분석 기반 (Xplatform + Web HTML)    ← 단독 셀
C7  프로젝트명        E7  누리미디어 통합관리시스템(BIS)
C8  전환 내용         E8  Xplatform → JSP 기반 Web 전환
...
C13 작성일           E13 2026-06-11
C15 상태            E15 1차 생성 - 검토 필요
B18 * 본 문서는 ...                        ← 단독 셀
```

라벨은 C열(C:D 병합), 값은 E열(E:G 병합)이다.

### 인식 규칙 — `xlsx_meta.py` (신규)

`read_cover_meta(wb, mapping, warns) -> dict`

1. **표지 시트 선택**: `mapping.cover.sheet`가 있으면 그것. 없으면 화면 시트로 쓰이지 않은
   첫 시트.
2. **라벨-값 쌍**: 텍스트가 있는 셀에 대해 같은 행 오른쪽으로 스캔해 첫 비어 있지 않은
   값을 찾는다(병합 영역은 건너뛴다). 찾으면 `meta[라벨] = 값`.
3. **단독 셀**: 오른쪽에 값이 없는 셀 중 최상단을 `meta["문서제목"]`, 그다음을 `meta["부제"]`로
   둔다. 세 번째부터는 무시한다(주석·면책 문구이므로).
4. **오버라이드**: `mapping.meta_overrides`가 있으면 그 값이 이긴다. 양식이 규칙에서 벗어날 때
   사람이 지정하는 탈출구다.

값은 모두 문자열로 정규화한다(날짜는 `YYYY-MM-DD`).

표지 시트를 못 찾으면 `meta`를 비운다. **새 경고 코드를 만들지 않는다** — 경고 코드는
아홉 개로 고정이고 이 상황에 맞는 것이 없다. 대신 `extract.py`의 출력에
"표지 시트를 찾지 못해 문서 정보를 비웠습니다" 한 줄을 남긴다. 문서 정보가 비어도
화면 페이지 생성은 정상 진행되므로 화면 단위 경고로 다룰 대상이 아니다.

### `extract.py` 변경

`extract.py:69`의 하드코딩을 걷어낸다.

```python
# before
"meta": {"title": "화면설계서", "source": ..., "template": ...}

# after
"meta": {**cover_meta, "source": ..., "template": ...}
```

`문서제목`이 있으면 그것이 문서 제목이 된다. 없으면 `"화면설계서"`로 떨어진다.
`source`·`template`은 예약 키로 유지하며, 표지에 같은 이름의 라벨이 있어도 덮어쓰지 않는다.

## 6. `build.py`의 meta 채우기

`build.py:83-89`가 이미 화면별 `fields` → 동명 도형 경로를 갖고 있다. 문서 단위로 같은 규칙을
하나 더 둔다.

```
template.shapes 의 각 (key, shape_name) 에 대해
  값 = screen.fields[key]  if 있으면
     = meta[key]           elif 있으면
     = 건너뜀
```

**우선순위: 화면별 `fields` > 문서 `meta`.** 화면마다 다른 값이 있으면 그게 이긴다.

`build.py`는 여전히 `screens.json`과 `mapping.json`만 읽는다. openpyxl 비의존 제약은
그대로 유지되고, `tests/test_build.py`의 소스 검사도 통과한다.

## 7. `default_template.py` / `analyze.py`

`build_default_template(path, ..., meta_keys=None)`가 키 목록을 받는다. openpyxl은 모른다.

하단 바 폭이 10.83 in이고 글자가 6.5pt이므로 표지 아홉 항목을 모두 넣으면 잘린다.
**기본 템플릿이 만드는 meta 도형은 두 개다** — 4절 표의 자리를 그대로 쓴다.

- `문서제목` — 하단 바 좌측 (`L0 T6738252 W2648744 H100027`), 샘플에서 저작권 문구가
  있던 자리다. 남의 저작권 표기 대신 이 문서의 제목이 들어간다.
- `작성일` — 상단 우측 (`L8146752 T0 W504000 H144000`), 샘플에서 날짜가 있던 자리다.

쪽번호(`L4734198 T6716266`)는 meta가 아니라 슬라이드 번호이므로 별도로 둔다.

나머지 일곱 항목은 `meta`에 그대로 담기므로, 템플릿에 그 이름의 도형을 추가하기만 하면
코드 변경 없이 채워진다. `meta_keys`는 이 두 개를 넘어서는 도형을 만들지 않고,
`suggested_template_mapping.shapes`에 어떤 키가 담겼는지 알리는 용도로만 쓴다.

`analyze.py`가 표지에서 뽑은 키를 `meta_keys`로 넘기고,
`suggested_template_mapping.shapes`에 `문서제목`·`작성일`을 포함시킨다.
